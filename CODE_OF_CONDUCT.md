# Contributor Covenant Code of Conduct

This project follows the Contributor Covenant v2.1. We expect all contributors to uphold the code of conduct. Please see the full text below.

Our standards
- Be respectful and constructive.
- Seek to understand before responding.
- Harassment and exclusionary behavior will not be tolerated.

Enforcement
- Instances of abusive behavior should be reported to the repository owner via email or GitHub issues (private if needed). The maintainers will review and respond.

Full text and version
See: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
