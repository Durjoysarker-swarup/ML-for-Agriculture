# 🌾 Crop Recommendation System

A machine learning project that recommends the most suitable crop to cultivate based on soil nutrients (N, P, K) and climatic conditions (temperature, humidity, pH, rainfall). Two classification models — **Decision Tree** and **Random Forest** — are trained and compared, and the final model is used to generate single, top‑3, and batch crop recommendations.

## 🔎 Overview

Choosing the right crop for a given field condition is a critical decision in agriculture, directly impacting yield and farmer income. This project builds a supervised classification pipeline that takes seven soil and climate parameters as input and predicts the crop best suited to those conditions.

**Objectives:**
1. Explore and audit the crop recommendation dataset for quality issues.
2. Understand feature–crop relationships (nutrient/climate profile per crop).
3. Train and evaluate two classification models (Decision Tree, Random Forest).
4. Use the best-performing model to generate:
   - A single best crop recommendation
   - A top‑3 ranked recommendation with model confidence
   - Batch predictions from an external CSV file

## 📊 Dataset

The dataset (`Crop_recommendation.csv`) contains **2,200 records** across **22 crop classes**, with **100 samples per class** (perfectly balanced).

| Column        | Description                              | Type    |
|---------------|-------------------------------------------|---------|
| `N`           | Nitrogen content in soil                  | int     |
| `P`           | Phosphorus content in soil                | int     |
| `K`           | Potassium content in soil                 | int     |
| `temperature` | Temperature (°C)                          | float   |
| `humidity`    | Relative humidity (%)                     | float   |
| `ph`          | Soil pH value                             | float   |
| `rainfall`    | Rainfall (mm)                             | float   |
| `label`       | Target crop (22 classes)                  | object  |

**Data quality checks performed:**
- ✅ No missing values in any column
- ✅ No duplicate rows
- ✅ Target classes are perfectly balanced (100 samples each)
- ✅ Feature ranges sanity-checked (e.g., `ph` ranges from **3.50 to 9.94**, which is a physically plausible range for agricultural soils)

The 22 crop classes are:
`apple, banana, blackgram, chickpea, coconut, coffee, cotton, grapes, jute, kidneybeans, lentil, maize, mango, mothbeans, mungbean, muskmelon, orange, papaya, pigeonpeas, pomegranate, rice, watermelon`

## 🤖 Modeling

**Train/Test Split:** 80% training (1,760 rows) / 20% testing (440 rows), stratified on `label` to preserve class proportions in both sets. `random_state = 42` is used throughout for reproducibility.

### 1. Decision Tree Classifier
- `sklearn.tree.DecisionTreeClassifier(random_state=42)`
- Baseline interpretable model.

### 2. Random Forest Classifier
- `sklearn.ensemble.RandomForestClassifier(n_estimators=300, n_jobs=-1, random_state=42)`
- Ensemble model used for the final recommendation system due to superior accuracy and generalization.

## 🏆 Results

| Model              | Accuracy | Macro Avg F1 | Weighted Avg F1 |
|---------------------|:--------:|:-------------:|:-----------------:|
| Decision Tree        | 97.95%   | 0.98          | 0.98              |
| **Random Forest**    | **99.32%** | **0.99**     | **0.99**           |

**Observations from the confusion matrices:**
- Both models achieve near-perfect classification on most crops (18–20/20 test samples correct).
- The Decision Tree shows minor confusion between **blackgram**, **lentil**, **maize**, and **mothbeans**, and between **jute** and **rice** — crops with somewhat overlapping soil/climate profiles.
- The Random Forest reduces most of these misclassifications, confirming that ensembling multiple trees improves robustness against the natural overlap between agronomically similar crops.
- **Random Forest was selected as the final model** for the recommendation engine due to its higher accuracy and more balanced per-class performance.

## 🌱 Making Recommendations

The trained Random Forest model is used in three ways:

**1. Single best recommendation**
```python
new_conditions = pd.DataFrame({
    "N": [90], "P": [42], "K": [43],
    "temperature": [20], "humidity": [80],
    "ph": [6.5], "rainfall": [200]
})
recommended_crop = rf_model.predict(new_conditions)[0]
# → Recommended crop: rice
```

**2. Top‑3 ranked recommendations**
Uses `rf_model.predict_proba()` to rank all 22 crops by predicted probability and returns the top 3 candidates along with their confidence scores — useful when a farmer wants alternatives, not just a single answer.

**3. Batch prediction from a CSV file**
New field conditions can be supplied via `recommend_crop.csv` (same 7 feature columns, same order as training). The notebook loads this file, predicts a `best_crop` column for every row, and appends it to the dataframe.

```python
new_data = pd.read_csv("data/recommend_crop.csv")
new_data['best_crop'] = rf_model.predict(new_data)
```

> ⚠️ **Important:** Input features for prediction must follow the exact column order used in training: `['N', 'P', 'K', 'temperature', 'humidity', 'ph', 'rainfall']`.

## 🔑 Key Findings

- The dataset is clean (no missing values, no duplicates) and perfectly class-balanced, requiring minimal preprocessing.
- Soil nutrients and climate variables together produce highly separable clusters per crop — both tree-based models achieve **>97% accuracy** with almost no feature engineering.
- **Random Forest outperforms a single Decision Tree**, particularly on crops with agronomically similar profiles (e.g., legumes like blackgram, lentil, mothbeans), demonstrating the value of ensembling for this problem.
- Returning **top‑3 probability-ranked recommendations** (rather than a single label) provides more actionable, realistic guidance for end users, since real-world field conditions rarely map to a single "perfect" crop.
